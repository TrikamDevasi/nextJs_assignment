# Recipe Explorer

A recipe catalog and culinary exploration web application built with Next.js App Router, TypeScript, and Tailwind CSS.

## Overview
Recipe Explorer allows users to browse culinary recipes, filter by category and cuisine, search by ingredients or recipe title, and view detailed step-by-step cooking instructions with checkable ingredients.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Getting Started
Run the development server:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
